### Desktop Widget v1.0.0

Компактный горизонтальный оверлей для мониторинга ресурсов системы поверх всех окон и игр.

#### 🚀 Возможности:
* Отображение времени, загрузки CPU, RAM, GPU и показателей FPS.
* Переключение тем оформления (Тёмная / Светлая).
* Поддержка сквозных кликов для комфортной игры.

#### ⌨️ Горячие клавиши:
* `Ctrl` + `Shift` + `L` — Включить / выключить блокировку кликов (режим для игр).
* `Ctrl` + `Shift` + `T` — Переключить тему (Тёмная / Светлая).
* `Ctrl` + `Shift` + `H` — Скрыть / показать виджет.
* `Ctrl` + `Shift` + `Q` — Выход из программы.

#### 📌 Инструкция по запуску:
1. Скачайте `DesktopWidget.exe` ниже.
2. Запустите файл **от имени администратора**.
3. В играх используйте режим **«Оконный без рамок» (Borderless Windowed)** для отображения поверх игры.
